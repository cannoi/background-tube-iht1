8. YOUTUBE API INTEGRATION

Integrate YouTube Data API v3.

Use the developer-owned API key configured through an environment variable or secure application configuration.

IMPORTANT:

- Never hard-code the API key directly into UI source code.
- Never display the API key to users.
- Never commit the API key to GitHub.
- Provide a configuration field such as:

"YOUTUBE_API_KEY"

The application must read the key from the configured environment/secret.

Use the API only for permitted public-data operations.

Implement:

- Search
- Video metadata
- Channel metadata where needed
- Playlist metadata where permitted

Use efficient requests and pagination.

Handle:

- Invalid API key
- API disabled
- Quota exceeded
- Network error
- Rate limit
- Video unavailable
- Empty result

9. API CONFIGURATION

Create a clear configuration mechanism:

"YOUTUBE_API_KEY=YOUR_API_KEY_HERE"

Do not place the real key in the generated source code.

If the deployment environment supports secrets, use the secret/environment-variable system.

If the Builder requires configuration during deployment, clearly tell the user:

“Set YOUTUBE_API_KEY before starting the application.”

Add an API test function that checks whether the configured key can access YouTube Data API v3.

- Do not bypass the restriction.

12. ERROR RESILIENCE

Never shut down the whole application because one feature fails.

Example:

If YouTube API fails:
→ Keep Library and Settings available.

If one video cannot play:
→ Skip/report that item without breaking the player.

→ Show Retry and keep the rest of the UI working.

Use clear messages such as:

- “YouTube connection unavailable.”
- “API quota reached.”
- “This content is unavailable.”
- “Please try again.”
